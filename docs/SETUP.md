# VexChat — запуск доработок (этапы 4–12)

## 1. База данных (обязательно, первым делом)
1. Откройте SQL-редактор вашей базы (Lovable Cloud → Database → SQL, или Supabase → SQL Editor).
2. Вставьте и выполните **весь** файл `drizzle/migrations/0003_migration.sql` (миграции 0000–0002 уже должны быть применены).
3. Если выполнение остановилось с ошибкой — пришлите текст ошибки целиком; не запускайте файл «по кускам».
4. После успеха попросите Lovable «перегенерировать типы Supabase» (файл `src/integrations/supabase/types.ts`). Без этого код работает, но типы новых таблиц неизвестны (поэтому используются обёртки из `src/lib/db.ts`).

## 2. Первый владелец (Owner)
Зарегистрируйтесь в приложении, затем выполните `drizzle/manual/make_owner.sql` (подставьте свой e-mail).
Остальным ролям выдавайте через `/admin → Роли`.

## 3. Звонки
Работают в браузере по WebRTC. Для связи между разными сетями нужен TURN-сервер.
Добавьте секреты проекта: `TURN_URLS` (например `turn:turn.example.com:3478,turns:turn.example.com:5349`), `TURN_USERNAME`, `TURN_CREDENTIAL`.
Без них звонок идёт только через STUN и в части сетей не соединится (приложение об этом предупреждает).

## 4. Фоновые задачи
Миграция пытается включить `pg_cron` и создать 3 задачи (`vexchat-*`). Проверка — `/admin → Здоровье`.
Если pg_cron недоступен: исчезающие сообщения скрываются, но физически не удаляются; отложенные сообщения не создают уведомление; зависшие звонки закрываются при следующем звонке.

## 5. PWA / Android
PWA: `public/manifest.webmanifest`, `public/sw.js` (только в продакшене). Установка — «Добавить на главный экран».
Android: `docs/ANDROID.md`.

## Известные ограничения
- Не реализованы: push-уведомления при закрытом приложении, статус «в сети», шифрование end-to-end, перевод интерфейса на en/uz, загрузка аватарки группы.
- Сообщение, отклонённое лимитом частоты, молча не сохраняется (в БД пишется событие антиспама) — клиент показывает «слишком частая отправка».
- Файлы удалённых/исчезнувших сообщений остаются в Storage (нужна отдельная очистка).
- Статус резервных копий нельзя прочитать автоматически — раздел «Резервные копии» хранит только ручные отметки.
- Роль в интерфейсе скрывает кнопки, но реальные права проверяет только БД (RPC + RLS).
